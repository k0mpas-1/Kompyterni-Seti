## 1. Сеть `192.168.0.0/24`

### Условие

Нужно разделить сеть на **5 подсетей**, в каждой из которых должно быть минимум **25 хостов**.

### Решение

Для этого подходит маска `/27`:

* **Маска:** `255.255.255.224`
* **Количество подсетей:** 8
* **Количество доступных хостов в каждой подсети:** 30

Нам нужны только первые 5 подсетей.

| № | Диапазон подсети                |
| - | ------------------------------- |
| 1 | `192.168.0.0 – 192.168.0.31`    |
| 2 | `192.168.0.32 – 192.168.0.63`   |
| 3 | `192.168.0.64 – 192.168.0.95`   |
| 4 | `192.168.0.96 – 192.168.0.127`  |
| 5 | `192.168.0.128 – 192.168.0.159` |

**Ответ:** используется маска `/27`, которая позволяет получить 8 подсетей по 30 хостов. Из них используются первые 5.
