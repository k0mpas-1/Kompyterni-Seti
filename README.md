# Компьютерные сети

Добро пожаловать в репозиторий курса «Компьютерные сети»! Здесь собраны конспекты лекций, практические задания, скриншоты и дополнительные материалы по изучению компьютерных сетей.

## О курсе

Курс посвящён изучению принципов работы компьютерных сетей: от модели OSI и технологии Ethernet до настройки сетевого оборудования Cisco, расчёта подсетей и работы сетевых протоколов.

Материалы помогают изучить теорию, закрепить знания на практике и разобраться с основными сетевыми технологиями.

## Как устроена работа

- **Единый репозиторий.** Все конспекты, задания и дополнительные материалы собраны в одном месте.
- **Материалы по урокам.** Файлы распределены по папкам в соответствии с темами занятий.
- **Практические задания.** В репозитории представлены материалы для изучения и выполнения практических работ.
- **Скриншоты и документы.** Дополнительные файлы помогают разобраться в заданиях и примерах конфигураций.

## Структура репозитория

- **Lesson_1_OSI** — модель OSI и основы сетевого взаимодействия.
- **Lesson_2_Ethernet** — технология Ethernet и MAC-адресация.
- **Lesson_3_Cisco** — материалы по Cisco и расчёту подсетей.
- **Lesson_4_Cisco** — дополнительные материалы по настройке Cisco.
- **Lesson_5_Cisco** — практические материалы по конфигурации Cisco.
- **Lesson_6_PodSeti** — расчёт и настройка подсетей.
- **Lesson_7_Konspekt** — конспекты лекций.
- **Lesson_8_DNS** — материалы по DNS.
- **Lesson_9_Cisco** — дополнительные материалы по Cisco и NAT.
- **Lesson_10_TCP_UPD_Konspekt** — конспекты по протоколам TCP и UDP.
- **Lesson_11_TCP_UPD_skrins** — скриншоты и материалы по TCP/UDP.
- **Lesson_12_Cisco** — дополнительные материалы по Cisco.
- **Lesson_13_Komp** — дополнительный материал по HTTP
- **Samostoyatelnie** — материалы для самостоятельных работ.

## Как использовать репозиторий

1. Откройте репозиторий и выберите папку нужного урока.
2. Изучите конспекты и дополнительные материалы.
3. Ознакомьтесь со скриншотами и документами, если они представлены в папке.
4. Выполните соответствующие практические или самостоятельные задания.
5. Сохраняйте выполненные работы в соответствующих папках.

## Заключение

Репозиторий объединяет учебные материалы по курсу «Компьютерные сети» и позволяет удобно ориентироваться в темах занятий, находить нужные документы и возвращаться к пройденному материалу.
